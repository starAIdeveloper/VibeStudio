03 / Work your way

Keep the controls
that feel familiar.

VibeStudio brings classic editing habits into a shared workspace. The same project services also power a documented command line for diagnostics, package operations and automation.

  • Choose an editor profileProfiles inspired by GtkRadiant, NetRadiant Custom, TrenchBroom and QuArK adapt keys, gestures, cameras and layouts. Behaviour parity is partial.
  • Shape the interface around youHigh-visibility themes, scalable text, keyboard navigation and reduced motion are part of the studio. Accessibility testing remains incomplete.
  • Use AI when you chooseThe optional assistant is off by default. Core editing, building, packaging and CLI work do not require cloud AI. Agentic workflows are planned.

04 / Know where it stands

Explore an evolving studio.

VibeStudio is pre-alpha and largely untested in real projects. Automated coverage is a starting point; it does not establish production readiness.

Try it with copies of your work. Expect rough edges, missing pieces and bugs. Keep backups, and check the project status before adopting a workflow.

Available

Package operations and the CLI. Implemented and covered by automated tests, but not yet proven in real projects.

Partial

Most authoring and integration workflows. Levels, models, textures, audio, materials, code, builds and accessibility work within documented limits. Linux audio playback and recording are unavailable.

Planned

Further studio capabilities. Sprite animation editing and agentic AI workflows remain future work. Language registration does not mean completed translations.
